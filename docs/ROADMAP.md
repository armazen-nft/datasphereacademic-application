# Roadmap

## Curto Prazo
- Consolidar cobertura de testes para fluxos de submissão, comentários e validação.
- Evoluir módulos de IA para produzir rastreabilidade e explicabilidade por decisão.
- Padronizar contratos de API para integração futura com parceiros externos.

## Médio Prazo
- Introduzir camada de execução de scripts com sandbox para operadores customizados.
- Implementar registro/versionamento de scripts e política de aprovação.
- Adicionar traduções de payload por parceiro (bridge scriptável).

## Longo Prazo
- Expandir ecossistema de métricas customizadas orientadas por comunidade.
- Incorporar simulações de parceiros (mocks) para reduzir dependência de APIs externas em desenvolvimento.
- Evoluir governança técnica para operação multiagente com trilha de auditoria completa.
