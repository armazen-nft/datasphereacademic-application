# Contribuindo com o Datasphere Academic

Obrigado por considerar contribuir com o projeto! 🚀

## Antes de começar
- Siga o guia de setup em `QUICKSTART.md`
- Leia as regras de governança e revisão em `GOVERNANCE.md`

## Fluxo recomendado
1. Faça um fork do repositório
2. Crie uma branch: `feature/nome-da-tarefa`
3. Faça commits no padrão Conventional Commits
4. Abra um Pull Request com contexto claro da mudança

## Revisão
- PRs são revisados pelo Comitê Científico em até 48 horas
- Contribuições aprovadas contam no sistema de reputação
